# Drema — Manifesto

Construir ou reformar um imóvel deveria ser um dos momentos mais felizes da vida. Hoje é um processo cansativo: meses sem saber por onde começar, bons profissionais invisíveis, informação espalhada entre WhatsApp, papel e memória de quem contratou.

A Drema existe para organizar essa jornada. Isso não muda com a tecnologia — muda só a forma como é entregue.

## Princípios

1. Construir um imóvel é complexo; o cliente nunca deve sentir essa complexidade.
2. Ninguém procura "um profissional" — procura realizar um objetivo. A Drema traduz o objetivo em próximos passos.
3. Mostrar sempre o próximo passo, nunca todos de uma vez.
4. Cada tela existe para reduzir ansiedade, nunca para adicionar informação.
5. Toda decisão de produto deve economizar tempo do usuário.
6. Confiança vale mais que crescimento rápido.

Esses princípios servem para decidir o dia a dia do produto, não para enfeitar parede. Quando uma feature fica em dúvida, a pergunta é: ela serve a algum destes pontos?

Acompanhar o imóvel além da contratação (histórico de projeto, materiais, garantias — o "prontuário do imóvel") está registrado como direção de longo prazo, não como trabalho atual — ver [ROADMAP.md](ROADMAP.md) Fase 2 em diante. Regra do projeto: só expandir quando a fase anterior tiver métrica validada, não porque a visão é bonita.
